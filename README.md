# 🐈 ねこの帰り道 (lost_cat)

夜の街で迷子になった猫を操作して、おうちまで帰るブラウザゲームです。
目的地は地図に出ません。**猫が感じ取れるものだけ**が手がかりです。

▶ **遊ぶ**: https://nimnim1848.github.io/lost_cat/

## 遊び方

- 立ち止まって耳をすますと、車や犬などの音の向きが見えます
- 嗅ぐと、おうちの匂いの向きがわかります
- 見えない車は、音・足の裏の振動・ヘッドライトの光から推理して、道路をわたります
- 体力が0になるとゲームオーバー。茂みで休むと体力が回復します
- ダッシュはスタミナを使います。切れると息切れして走れません

## 操作

| | パソコン | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面右側をドラッグ |
| 嗅ぐ | Space | 左下ボタン |
| ダッシュ | Shift | 左下ボタン |
| 一時停止 | P | 右上ボタン |
| 音のオン/オフ | M | 右上ボタン |

## 特徴

- 毎回ランダムに生成される街(地区ごとに音・匂い・灯りが違う)
- 信号、渋滞、ウィンカーを出して曲がる車
- 他の猫のナワバリ、仲良しの猫、猫だけが通れる抜け道
- 隠し実績
- お題つきのチャレンジ(雨・風・霧・渋滞の夜)。街と条件が固定なので、同じ条件でスコアを比べられます

## 技術

`index.html` 1枚だけで動きます(HTML / Canvas / JavaScript)。ビルドや外部ライブラリは使っていません。音もブラウザ内で合成しています。
